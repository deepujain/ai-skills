# Maintain, learn, and replenish NemoClaw to exactly five healthy open PRs, then refresh live delivery state

## Playbook

Contribution Queue

## Done means

- [x] The live authored queue contains exactly five open PRs, never six.
- [x] Every open PR contains current `main`, is mergeable, has a valid GitHub
  signature and DCO, and passes exact-head local and GitHub validation.
- [x] Contributor-actionable review findings are fixed; external-only gates are
  identified without being mislabeled as contributor failures.
- [x] The latest ten merged peer PRs are scanned for durable lessons, and the
  final GitHub state is refreshed after publication.

## Constraints to preserve

- [x] Preserve each PR's existing scope and behavior while rebasing independent
  stacks; resolve conflicts from current repository evidence, not by choosing a
  whole side.
- [x] Use signed DCO commits and exact `--force-with-lease` publication.
- [x] Replenish only after a real departure and only below the live cap of five.
- [x] Do not manufacture local evidence for credential-backed or qualified
  release infrastructure that only maintainers control.

## Task list

- [x] Read the engineering principles, Contribution Queue playbook, shared OSS
  protocol, graph engineering reference, quality rules, and NemoClaw skill.
- [x] Reconcile the previous receipt with live authored PRs and repository cap.
- [x] Inspect exact heads, CI, reviews, comments, signatures, DCO, and base lag.
- [x] Preflight GitHub-recognized SSH signing before rewriting any stack.
- [x] Rebase each PR independently on current `main`, resolve conflicts with
  measured repository ownership, and publish with exact old-head leases.
- [x] Run focused tests plus pre-commit, commitlint, pre-push, nested workspace
  build, and diff checks on every exact head.
- [x] Re-read GitHub after publication and fix any contributor-owned finding.
- [x] Scan the ten latest merged peer PRs and update durable guidance only when
  the evidence adds a new reusable rule.
- [x] Skip replenishment: the live queue remained exactly 5/5 throughout.
- [x] Record and validate the final receipt, then refresh live delivery state.
